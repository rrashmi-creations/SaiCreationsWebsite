SAI CREATION SHOP - FRONT-END WEBSITE PACKAGE

Open index.html to view the storefront. No build tools needed.

Folder structure:
- index.html: main landing page
- styles.css: design/responsive layout
- app.js: products, cart, wishlist, admin and settings functionality
- images/kurties, images/coordsets, images/sarees, images/others: place product photos here

Image naming examples:
images/kurties/image1.jpg
images/kurties/image2.jpg
images/coordsets/image1.jpg
images/sarees/image1.jpg
images/others/image1.jpg

To show a photo on a product, Admin > Products > Edit (or Add Product) and paste its image path in Image path or URL.
Note: Sample products have placeholder image paths. Put your photos in matching folders and use paths in the product editor.

Admin password (initial): Admin@123
Use Admin Login at top. Change password after login in Admin > Change Password.

IMPORTANT LIMITATIONS:
This is a multi-file front-end storefront with local browser storage. Admin edits, products, settings, cart and wishlist are saved in the browser/device that made them. They do not sync to other phones or customers. Admin password is client-side and is NOT secure for public deployment. No real payment processing, inventory server, shipping/courier integration, or customer order database exists yet. WhatsApp checkout opens a prefilled message for the configured business number. Before public launch, connect a secure backend/database/authentication and payment/order services.
